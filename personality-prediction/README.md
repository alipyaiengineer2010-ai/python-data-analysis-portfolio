# Personality Type Prediction

This project focuses on predicting personality types using machine learning classification techniques. It involves data preprocessing, exploratory data analysis (EDA), and building classification models to understand the relationship between various features and personality traits.

## 🛠 Tech Stack
- Language: Python
- Libraries: Pandas, NumPy, Seaborn, Matplotlib, Scikit-Learn

## 📊 Project Workflow
1. Data Preprocessing: 
   - Handled missing values using fillna with median imputation.
   - Encoded categorical variables using LabelEncoder.
2. Exploratory Data Analysis (EDA):
   - Visualized dataset distribution using Seaborn (count plots).
   - Analyzed correlations to understand feature importance.
3. Modeling:
   - Implemented Logistic Regression and Decision Tree Classifier.
4. Evaluation:
   - Evaluated models using accuracy_score, classification_report, and confusion_matrix.

## 📈 Key Metrics
The models were evaluated based on their classification accuracy and ability to distinguish between different personality categories.
