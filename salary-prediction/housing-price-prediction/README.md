# 🏠 House Price Prediction using Linear Regression

A machine learning project focusing on predicting housing prices using multiple features, exploratory data analysis (EDA), and regression modeling.

---

## 📌 Project Overview
- Goal: Predict residential house prices based on features such as area, bedrooms, and location attributes.
- Dataset: Housing Dataset (housing.csv / Housing.csv).
- Domain: Supervised Learning / Regression.

---

## 🛠️ Tech Stack & Tools
- Python: Core programming language
- Pandas & NumPy: Data cleaning, handling missing values, and preprocessing
- Matplotlib & Seaborn: Correlation heatmaps and feature distribution plots
- Scikit-Learn: Feature scaling, Train/Test split, Linear Regression modeling, and evaluation metrics (MAE, RMSE, R²)
