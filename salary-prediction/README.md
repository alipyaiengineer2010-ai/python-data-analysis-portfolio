# 📈 Salary Prediction with Linear Regression

A foundational Machine Learning project to predict employee salary based on years of experience using Simple Linear Regression.

## 📌 Overview
- Goal: Predict employee salary based on years of experience.
- Dataset: Salary_Data.csv
- Algorithm: Linear Regression (Supervised Learning)

## 🛠️ Tech Stack & Tools
- Python
- Pandas & NumPy: Data loading, inspection, and statistics
- Matplotlib & Seaborn: Data visualization and scatter plot analysis
- Scikit-Learn: Data splitting (train_test_split) and LinearRegression model

## 📊 Workflow
1. Load and inspect dataset (head, info, describe, null check).
2. Visualize correlation between experience and salary using Seaborn.
3. Split data into training (80%) and testing (20%) sets.
4. Train Linear Regression model and evaluate predictions.
